# TextCleaner

TextCleaner is a small macOS menu bar app for cleaning copied text before pasting it elsewhere.

It can strip rich formatting by reading and writing plain clipboard text, fix PDF-style broken line breaks, normalize spaces, and convert capitalization.

## Use

1. Copy messy text from a PDF, website, email, or message.
2. Click TextCleaner in the menu bar.
3. Click `Clean Clipboard` to clean and copy the result back to the clipboard.
4. Paste anywhere.

You can also paste or edit text in the popover, run a specific cleanup action, and copy the output.
